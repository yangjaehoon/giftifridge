## 1. 개요

기프티냉장콘(이하 "앱")은 사용자가 보유한 모바일 상품권(기프티콘)을 등록·정리하고, 유효기간
알림과 근처 매장 알림을 제공하는 개인용 도구입니다. 앱은 상품권을 판매하거나 결제를
처리하지 않으며, 광고를 게재하지 않습니다.

앱은 별도의 회원가입 없이 실행 즉시 **익명 계정**으로 동작합니다. 사용자가 원하면 이메일 ·
비밀번호로 계정을 연결해 여러 기기에서 같은 데이터를 볼 수 있습니다.

## 2. 수집하는 개인정보 항목과 수집 방법

앱은 다음 정보를 처리합니다. 대부분은 사용자가 직접 입력하거나 앱 사용 과정에서 생성됩니다.

| 구분            | 항목                                                                               | 수집 방법                                   | 저장 위치                           |
| --------------- | ---------------------------------------------------------------------------------- | ------------------------------------------- | ----------------------------------- |
| 계정            | 익명 사용자 식별자(UID)                                                            | 앱 최초 실행 시 자동 생성                   | Firebase Authentication             |
| 계정(선택)      | 이메일 주소, 비밀번호                                                              | 사용자가 계정 연결 시 입력                  | Firebase Authentication             |
| 기프티콘        | 상품명, 브랜드, 카테고리, 유효기간, 바코드 번호, 금액·잔액, 사용 이력, 메모성 정보 | 사용자 입력 또는 이미지에서 자동 인식       | Cloud Firestore                     |
| 기프티콘        | 기프티콘 이미지(사진)                                                              | 사용자가 촬영하거나 사진첩에서 선택         | Firebase Storage                    |
| 매장 위치(선택) | 기프티콘에 연결한 매장의 좌표(위도·경도), 주소 문자열                              | 사용자가 "현재 위치" 저장 또는 주소 검색    | Cloud Firestore                     |
| 위치(선택)      | 근처 매장 알림을 위한 기기의 대략적/정밀 위치 (사용자 허용 시 백그라운드 포함)     | 앱 실행 중 또는 허용 시 백그라운드에서 측정 | 기기 내에서만 사용, 서버 저장 안 함 |
| 공유            | 스페이스 이름, 스페이스 구성원 UID, 참여 시각                                      | 사용자가 스페이스 생성·참여 시              | Cloud Firestore                     |
| 알림            | 푸시 알림 토큰, 예약된 로컬 알림 정보                                              | 알림 권한 허용 시 자동                      | 기기 및 Firebase Cloud Messaging    |
| 진단            | 앱 버전, 기기 종류·OS 버전, 실행/오류 등 집계 지표                                 | 자동                                        | Expo(EAS Insights)                  |

앱은 연락처, 통화 기록, 문자메시지, 오디오(마이크)를 수집하지 않습니다. 마이크 관련 권한은
빌드에서 제거되어 있습니다.

### 카메라 · 사진첩 · 온디바이스 인식

- **카메라**: 바코드 스캔과 기프티콘 촬영에만 사용합니다.
- **사진첩**: 사용자가 고른 이미지를 등록하거나, "새 사진 자동 등록" 기능을 켠 경우 새로
  추가된 스크린샷을 기기에서 검사해 기프티콘을 찾아냅니다. 자동 검사와 바코드·문자
  인식(ML Kit)은 **기기 내에서** 수행되며, 사용자가 등록을 확정한 이미지와 그 인식
  결과만 서버로 전송됩니다.

## 3. 개인정보의 이용 목적

- 기프티콘 등록·조회·정리 및 여러 기기 간 동기화
- 유효기간 임박 알림, 자주 가는 매장 근처에서의 미사용 기프티콘 알림
- 스페이스를 통한 가족·지인과의 기프티콘 공유
- 계정 인증 및 부정 사용 방지
- 오류 파악 및 서비스 품질 개선(집계 지표)

## 4. 위치정보의 처리

- 근처 매장 알림을 위해 기기 위치를 사용합니다. 서버로 전송하거나 저장하지 않고, 근처
  여부 판단 직후 폐기합니다.
- **백그라운드 위치(선택)**: 사용자가 별도로 허용한 경우에 한해, 앱을 열지 않은
  동안에도 저장된 매장 반경(약 160m)에 들어왔을 때만 위치를 확인해 알림을 보냅니다.
  이때도 위치는 기기 안에서만 사용하고 서버로 전송하거나 저장하지 않습니다. 이 권한은
  거부해도 앱을 실행 중일 때의 근처 매장 알림은 그대로 동작합니다.
- 사용자가 기프티콘에 매장 위치를 직접 저장한 경우, 그 좌표는 해당 기프티콘 정보의
  일부로 저장됩니다.
- 주소 검색 시 입력한 검색어는 좌표 변환을 위해 기기의 운영체제(및 그 지도 공급자)로
  전달될 수 있습니다.
- 위치 권한은 언제든지 기기 설정에서 해제할 수 있으며, 해제 시 근처 매장 알림만
  동작하지 않고 나머지 기능은 그대로 사용할 수 있습니다.

## 5. 제3자 제공 및 처리위탁

앱은 개인정보를 판매하거나 광고 목적으로 제공하지 않습니다. 서비스 운영에 필요한 범위에서
아래 사업자의 인프라를 이용합니다.

| 수탁자                | 위탁 업무                                             | 관련 항목                                              |
| --------------------- | ----------------------------------------------------- | ------------------------------------------------------ |
| Google LLC (Firebase) | 인증, 데이터베이스, 이미지 저장, 푸시 알림, 서버 기능 | 계정, 기프티콘, 이미지, 매장 위치, 스페이스, 알림 토큰 |
| Expo (EAS Insights)   | 앱 사용량·오류 집계                                   | 진단 지표                                              |

Firebase 데이터는 대한민국 리전(asia-northeast3, 서울)에 저장되도록 구성되어 있습니다.
서버 기능·푸시 처리 과정에서 Google의 글로벌 인프라를 통해 처리될 수 있습니다.

## 6. 보유 기간 및 파기

- 사용자가 앱에서 기프티콘·스페이스를 삭제하면 해당 데이터와 이미지는 지체 없이
  삭제됩니다.
- **미사용 익명 계정 자동 삭제**: 익명 계정으로 180일 동안 앱을 한 번도 실행하지 않으면,
  해당 계정과 그 계정이 등록한 모든 기프티콘·이미지가 자동으로 삭제됩니다. 이 안내는 앱
  최초 실행 시 표시됩니다.
- 사용자가 계정 삭제를 요청하면 아래 7항에 따라 계정과 관련 데이터를 삭제합니다.
- 관계 법령상 보존 의무가 있는 경우 해당 기간 동안 보관 후 파기합니다.

## 7. 이용자의 권리와 계정·데이터 삭제

- **인앱 삭제**: 앱의 `설정` 화면에서 `계정 삭제`를 실행하면, 계정과 함께 사용자가 등록한
  기프티콘·이미지, 사용자가 만든 스페이스, 스페이스 참여 기록이 서버에서 영구 삭제됩니다.
  이 작업은 되돌릴 수 없습니다.
- **문의를 통한 삭제**: 인앱 삭제가 어려운 경우 【 연락 이메일 】 로 요청하시면 본인 확인 후
  처리합니다.
- 이용자는 자신의 개인정보에 대한 열람·정정·삭제·처리정지를 요청할 수 있습니다.
- 기기 설정에서 카메라·사진·위치·알림 권한을 개별적으로 허용하거나 해제할 수 있습니다.

## 8. 개인정보의 안전성 확보 조치

- 저장·전송 구간 암호화(HTTPS/TLS)
- 서버 측 보안 규칙으로 본인 또는 같은 스페이스 구성원만 데이터에 접근하도록 제한
- 최소 권한 원칙에 따른 접근 통제

않습니다. 아동의 정보가 수집된 사실을 확인하면 지체 없이 삭제합니다.
